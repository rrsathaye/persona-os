# AI Provider Routing

## Goal

PersonaOS should never depend on a single AI provider.

Supported providers:

- OpenAI
- Claude
- Gemini
- Grok
- DeepSeek
- Ollama / Local Models

## Initial Version

User manually selects provider.

## Future

PersonaOS automatically routes requests.

Possible routing criteria:

- Cost
- Latency
- Context window
- Quality
- User preference
- Availability
- Privacy
