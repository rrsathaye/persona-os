# Product Ideas

## Floating PersonaOS Assistant

Long-term vision:

A floating PersonaOS orb appears over supported applications.

Examples:

- Reddit
- Gmail
- LinkedIn
- Slack
- WhatsApp
- Teams

Flow:

User opens application

↓

PersonaOS reads the visible screen (with user permission)

↓

Understands:

- context
- sentiment
- platform
- conversation
- writing style

↓

Shows:

"Draft ready"

↓

User taps

↓

PersonaOS opens with a generated draft.
